# Source data

`osm_rdf/` contains the OSM-derived graph and aligned spatial features used by
the GeoAnchor entity encoder. It includes the selected entity table, geometry
records, entity and relation indexes, the 38-dimensional feature matrix, and
the graph triple splits.

These files are derived inputs rather than the original OSM dump. See
`../../DATA_CARD.md` and `../../THIRD_PARTY_NOTICES.md` for provenance and
upstream data conditions.
